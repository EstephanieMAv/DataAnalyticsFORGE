SuperTienda — Portafolio de Análisis de Datos

SuperTienda es una cadena de retail multicanal con presencia en las regiones Norte, Centro, Sur y Austral, cuya gerencia identificó una necesidad crítica: pese a mantener ventas totales estables, no contaba con visibilidad clara sobre qué perfiles de clientes generaban realmente el mayor valor para el negocio, ni sobre qué porción de su base de 300 clientes había dejado de comprar sin que nadie lo detectara a tiempo. Este proyecto aborda ese problema de negocio construyendo un proceso analítico completo: desde la extracción y consolidación de los datos dispersos en la base relacional de la empresa, hasta la identificación de segmentos de clientes con comportamientos de compra diferenciados.

Para esto se utilizó SQL para consultar y extraer la información desde la base de datos relacional original, Python (pandas, scikit-learn) para la limpieza, el procesamiento del dataset y la aplicación de un modelo de segmentación por clustering (K-Means), y Power BI para construir un panel de control interactivo que permite explorar los hallazgos por región, canal, segmento y período. El objetivo de este portafolio es servir como una herramienta de diagnóstico integral para la gerencia de SuperTienda: no solo documenta el proceso técnico realizado, sino que traduce los hallazgos de datos en recomendaciones de negocio concretas, dando a la dirección un criterio objetivo y basado en evidencia para decidir dónde priorizar sus recursos comerciales.
